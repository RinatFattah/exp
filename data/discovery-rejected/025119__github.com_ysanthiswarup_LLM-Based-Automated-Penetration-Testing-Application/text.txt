## 💻 Project Abstract:  
The **LLM-Based Automated Penetration Testing Application** is a cutting-edge cybersecurity tool designed to automate and enhance penetration testing using a Large Language Model (LLM). This project aims to develop a **production-quality prototype** capable of autonomously identifying security vulnerabilities in the authorized systems, networks, and applications.  

### Key Features:  
- **AI-Driven Pentesting**: The system will leverage an LLM to generate, optimize, and execute penetration testing scripts, reducing manual effort, time and improving testing efficiency.  
- **Metasploit Integration**: The framework will seamlessly integrate with Metasploit to automate exploit execution and vulnerability assessment.  
- **Automated Vulnerability Analysis**: The system will analyze the security flaws, generate structured reports, and provide risk assessments to help organizations mitigate threats.  
- **Scalability & Usability**: A web-based interface will be developed to facilitate user interaction, making the tool accessible to security professionals and organizations.

### 1. Kali Linux VM

1. Download **Kali Linux ISO**
2. Install **VirtualBox**
3. Create a new VM in VirtualBox:
   - Type: `Linux`
   - Version: `Debian (64-bit)`
   - Memory: `4096 MB`
   - Storage: `20 GB`
4. Attach the Kali ISO and complete the installation.

### 2. Metasploitable 2 VM

1. Download and extract the `.zip` file
2. In VirtualBox → New VM:
   - Name: `Metasploitable`
   - Type: `Linux`, Version: `Ubuntu (64-bit)`
   - Memory: `2048 MB`
   - Use existing `.vdi` disk file
3. Go to `Settings → Network → Adapter 1`:
   - Set to `Bridged Adapter`
4. Start and log in with:
   - Username: `msfadmin`
