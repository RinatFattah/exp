# Prompt Injection Attacks on Educational LLM Graders

Reproduction of the attack framework from:

> Cai, Y. (2026). *Prompt Injection Attacks on Educational Large Language Models for Higher and Vocational Education*. Scientific Reports. https://doi.org/10.1038/s41598-026-46563-1

This repository implements **four prompt injection attack methods** against an LLM-based educational grader, demonstrating how adversarial student inputs can manipulate automated scoring outcomes.

> **Research use only.** This code is provided for academic study of LLM security vulnerabilities in educational systems.

---

## Attacks Implemented

| Attack | Description | Paper Reference |
|--------|-------------|-----------------|
| `rubric_aligned` | Embeds a rubric-mirroring self-assessment span mid-answer (paper's main method) | Sec 4 |
| `cot_hijacking` | Appends a step-by-step scoring argument to bias the grader's reasoning | Sec 5.4 |
| `naive_override` | Appends an explicit instruction to ignore the rubric and assign full marks | Sec 5.4 |
| `jailbreak` | Appends a role-play persona (GraderDAN) to suppress rubric application | Sec 5.4 |

## Installation

Python 3.10+ is required. No external packages are needed for mock mode.

```bash
git clone https://github.com/CYC7b/Prompt-Injection-Attacks-on-Educational-LLM-Graders.git
cd Prompt-Injection-Attacks-on-Educational-LLM-Graders
```

For a real LLM backend, install the corresponding package:

```bash
pip install openai      # OpenAI-compatible APIs (optional)
pip install anthropic   # Anthropic Claude (optional)
```

---

## API Configuration

Copy `.env.example` to `.env` and fill in your credentials:

```bash
cp .env.example .env
```

### SiliconFlow (default)

The default backend uses [SiliconFlow](https://siliconflow.cn/) with `Qwen/Qwen3.6-27B`:

```env
SILICONFLOW_API_KEY=your_siliconflow_api_key_here
SILICONFLOW_MODEL=Qwen/Qwen3.6-27B
SILICONFLOW_BASE_URL=https://api.siliconflow.cn/v1
SILICONFLOW_TIMEOUT_SECONDS=180
SILICONFLOW_RETRIES=3
SILICONFLOW_MAX_TOKENS=700
```

### OpenAI-compatible endpoint (optional)

```env
OPENAI_API_KEY=your_openai_api_key_here
LLM_MODEL=gpt-4o-mini
```

### Anthropic Claude (optional)

```env
ANTHROPIC_API_KEY=your_anthropic_api_key_here
LLM_MODEL=claude-3-5-haiku-20241022
```

If no API key is configured, the runner uses **mock mode** — simulating grader responses locally with no network calls.

## Running the Attacks

```bash
# Run all four attacks on the KCL short-answer case (default)
python run_demo.py

# Run all attacks on the essay case
python run_demo.py --case essay

# Run a single attack
python run_demo.py --attacks rubric_aligned --case kcl
python run_demo.py --attacks cot_hijacking --case essay
python run_demo.py --attacks naive_override
python run_demo.py --attacks jailbreak
```

### Available test cases

| `--case` | Description |
|----------|-------------|
| `kcl` | Kirchhoff's Current Law short answer (3-dimension rubric) |
| `essay` | Renewable energy essay (5-dimension rubric) |
| `mcq_just` | Multiple-choice question with justification |

```
  breakdown  = {"Correctness": 8.0, "Explanation Quality": 7.0, "Completeness": 3.0}
  rationale  = ...

─────────────────────────────────────────────────────────────────────────────
 ATTACK: rubric_aligned
─────────────────────────────────────────────────────────────────────────────
  attack    : rubric_aligned (Embedded, rubric-mirroring self-assessment)
  objective : score inflation
  notes     : payload_source=siliconflow; rubric_terms=[...]

  --- attacked student input ---
  ...

  --- attacked grader output ---
  score      = 7.0
  breakdown  = {"Correctness": 9, ...}
  rationale  = ...

  deviation       : 0.10
  grade_delta     : +0.10  (success threshold τ=+0.01)  ->  SUCCESS
```
