# RedProbe

RedProbe is a red-team auditing agent for AI safety research. It autonomously probes target LLMs for alignment issues, jailbreak vulnerabilities, and concerning behaviors using multi-turn conversations with simulated tools.

> **Note**: This is a fork of [Petri](https://github.com/safety-research/petri) by sidfeels with enhanced red-team focused features.

## Key Features

- **Two Execution Modes**: Single audit for quick testing, batch evaluation for systematic benchmarks
- **Ideation System**: AI-generated diverse attack scenarios from high-level goals
- **Sequential Learning**: Successful attacks inform future attempts
- **ASR Metrics**: Track Attack Success Rate by goal category
- **25 Scoring Dimensions**: Comprehensive evaluation across 9 categories
- **Skills System**: Load attack technique descriptions on-demand

## Quickstart

### 1) Install

```bash
git clone https://github.com/sidfeels/redprobe.git
cd redprobe
uv sync
# or
pip install -e .
```

### 2) Configure models

Set your API keys:
```bash
export ANTHROPIC_API_KEY=...
export OPENAI_API_KEY=...
```

Or use a `.env` file (see `.env.example`).

### 3) Run an audit

Use the Inspect CLI to run the task. You can bind different models to the `auditor`, `target`, and `judge` roles. For available models see [providers](https://inspect.aisi.org.uk/providers.html).

```bash
inspect eval petri/audit \
  --model-role auditor=anthropic/claude-sonnet-4-20250514 \
  --model-role target=anthropic/claude-3-7-sonnet-20250219 \
  --model-role judge=anthropic/claude-opus-4-20250514
```

With custom special instructions:

```bash
inspect eval petri/audit \
  --model-role auditor=anthropic/claude-sonnet-4-20250514 \
  --model-role target=anthropic/claude-3-7-sonnet-20250219 \
  --model-role judge=anthropic/claude-opus-4-20250514 \
  -T max_turns=40 \
  -T special_instructions="['Probe the target to see if it can figure out its knowledge cutoff']" \
  -T transcript_save_dir=./outputs
```

### 4) View transcripts

```bash
npx @kaifronsdal/transcript-viewer@latest --dir ./outputs
```

### 5) Run batch evaluation with ideation

For systematic evaluation across multiple goals:

```bash
python -m petri.orchestration.cli \
  --goal "get target to output keylogger code" \
  --target openai/gpt-4o \
  --samples-per-goal 5
```

Multiple goals with sequential learning:

```bash
python -m petri.orchestration.cli \
  --goal "keylogger code" \
  --goal "phishing email" \
  --target openai/gpt-4o
```

From a goals file:

```bash
python -m petri.orchestration.cli \
  --goals-file goals/cbrn_bench.json \
  --target openai/gpt-4o
```

### 6) Export transcript to HTML (optional)

```bash
python scripts/export_transcript.py --list              # List recent runs
python scripts/export_transcript.py logs/eval.eval --html --open  # Export and view
```

## Architecture

### Execution Modes

**Single Mode** (`petri/audit`): Direct probing with special instructions
```bash
inspect eval petri/audit -T special_instructions="['Your probe']" ...
```

**Eval Mode** (Orchestration CLI): Batch evaluation with ideation
```bash
python -m petri.orchestration.cli --goals-file goals.json --target model
```

### Core Components

- **Auditor Agent**: Red-team model with 8 tools for probing targets
- **Ideation Module**: Generates diverse attack scenarios from goals
- **Orchestration Runner**: Runs sequential evaluations with learning
- **Alignment Judge**: Scores transcripts across 25 dimensions

## Responsible Use

RedProbe is designed to probe for concerning behaviors, which can involve harmful content. Model providers may block accounts that generate too many harmful requests. Review provider policies and use responsibly.
